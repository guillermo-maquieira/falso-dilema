# Falso Dilema

Create a quiz style game named "Falso Dilema" (hosted on falso-dilema.lovable.app) based on  question and answers that can be managed via a simple admin. A question will have some emojis and an answer will have 2 or 3 possible text based answers. Use as few as possible credits.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://falso-dilema.lovable.app

## Build with Lovable
